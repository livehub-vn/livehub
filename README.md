# LiveHub Landing

Trang giới thiệu cho nền tảng kết nối dịch vụ livestream có kiểm duyệt.

## Storyline

`Đăng → Duyệt → Kết nối`

- Khách hàng tìm dịch vụ hoặc đăng nhu cầu.
- Nhà cung cấp đăng dịch vụ hoặc ứng tuyển dự án.
- LiveHub duyệt nội dung, kiểm tra lịch và quản lý kết nối.

Tài liệu đầy đủ: [`../docs/livehub-product-story.md`](../docs/livehub-product-story.md)

## Chạy dự án

```bash
pnpm install
pnpm dev
```

## Kiểm tra

```bash
pnpm lint
pnpm typecheck
pnpm build
```
